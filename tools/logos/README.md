# Logos für die Werkbank / Logos for the workbench

Die Schildchen in Blatt 02 („Die Werkbank“) zeigen, womit ich arbeite. Die Logos gehören ihren Inhabern. Sie stehen hier nur, um die Sprache oder das Werkzeug zu benennen, nicht als Werbung oder Empfehlung von ihnen.

The badges in sheet 02 (“The workbench”) show what I work with. The logos belong to their owners. They only name the language or tool, they are no endorsement.

| powershell.svg, vscode.svg, batch.svg, innosetup.svg | eigene Zeichnung / my own drawing (Simple Icons führt keine Microsoft-Logos) | wie dieses Repo / same as this repo |

Die Farben stehen in `tools/readme-bauen.mjs` (`SCHILDCHEN`). Wo eine Markenfarbe auf der dunklen Fläche keine 3:1 schafft (CSS, GitHub), hellt das Bauskript sie auf.
